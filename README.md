
# GroupChatBrief

A Chrome extension for WhatsApp Web that turns your busy group chats into short summaries and a daily action plan.

## What it does
- You choose which groups it reads. Nothing else is touched.
- Summarises each selected group: what was discussed, decided and planned.
- Builds a daily action plan: deadlines, events, and chats waiting on your reply.
- Add items to Google Calendar and get reminders.
- Looks at the last 30 days only.

## Privacy
- Uses your own Gemini API key. The key stays in your browser.
- Messages from your selected groups are sent to Gemini to be summarised.
- Groups only. Personal chats are not read.

## Install
1. Download this repository and unzip it.
2. Open chrome://extensions and turn on Developer mode.
3. Click Load unpacked and select the extension folder.
4. Open web.whatsapp.com, then click the GroupChatBrief icon.
5. Paste your Gemini API key and press Connect Now.
6. Open Groups, tick the groups you want, and run a scan.
